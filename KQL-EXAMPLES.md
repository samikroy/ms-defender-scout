## 🔍 Security Posture Assessment

### 1. Device Security Overview

**Use Case:** Get a comprehensive view of device security status

```kql
DeviceInfo 
| where Timestamp > ago(1d) 
| summarize 
    TotalDevices = dcount(DeviceId),
    OnboardedDevices = dcountif(DeviceId, OnboardingStatus == "Onboarded"),
    HighRiskDevices = dcountif(DeviceId, DeviceRiskScore == "High"),
    MediumRiskDevices = dcountif(DeviceId, DeviceRiskScore == "Medium"),
    LowRiskDevices = dcountif(DeviceId, DeviceRiskScore == "Low")
| extend OnboardingRate = round((OnboardedDevices * 100.0) / TotalDevices, 2)
| project TotalDevices, OnboardedDevices, OnboardingRate, HighRiskDevices, MediumRiskDevices, LowRiskDevices
```

### 2. Vulnerability Exposure Score

**Use Case:** Calculate overall vulnerability exposure across the organization

```kql
DeviceTvmSoftwareVulnerabilities
| summarize 
    CriticalCount = countif(VulnerabilitySeverityLevel == "Critical"),
    HighCount = countif(VulnerabilitySeverityLevel == "High"),
    MediumCount = countif(VulnerabilitySeverityLevel == "Medium"),
    LowCount = countif(VulnerabilitySeverityLevel == "Low")
| extend ExposureScore = (CriticalCount * 10) + (HighCount * 5) + (MediumCount * 2) + (LowCount * 1)
| project CriticalCount, HighCount, MediumCount, LowCount, ExposureScore
```

### 3. Security Update Status

**Use Case:** Identify devices with outdated security updates

```kql
DeviceInfo
| where Timestamp > ago(1d)
| where OSPlatform == "Windows"
| summarize arg_max(Timestamp, *) by DeviceId
| extend DaysSinceLastUpdate = datetime_diff('day', now(), Timestamp)
| where DaysSinceLastUpdate > 30
| project DeviceName, OSVersion, DaysSinceLastUpdate, OnboardingStatus
| order by DaysSinceLastUpdate desc
```

## 🎯 Threat Hunting

### 4. Lateral Movement Detection

**Use Case:** Detect potential lateral movement using PsExec or similar tools

```kql
DeviceProcessEvents
| where Timestamp > ago(24h)
| where FileName in~ ("psexec.exe", "psexec64.exe", "paexec.exe")
    or ProcessCommandLine has_any ("\\\\", "psexec", "accepteula")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName
| order by Timestamp desc
```

### 5. Credential Dumping Attempts

**Use Case:** Identify potential credential theft activities

```kql
DeviceProcessEvents
| where Timestamp > ago(7d)
| where FileName in~ ("mimikatz.exe", "procdump.exe", "procdump64.exe")
    or ProcessCommandLine has_any ("lsass", "sekurlsa", "logonpasswords")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, SHA256
| join kind=leftouter (
    AlertInfo
    | where Timestamp > ago(7d)
    | project AlertId, Title, Severity
) on $left.SHA256 == $right.SHA256
| order by Timestamp desc
```

### 6. Living Off the Land (LOLBins)

**Use Case:** Detect abuse of legitimate Windows binaries

### 7. Suspicious PowerShell Encoded Commands

**Use Case:** Find PowerShell commands with Base64 encoding

```kql
DeviceProcessEvents
| where Timestamp > ago(24h)
| where FileName =~ "powershell.exe" or FileName =~ "pwsh.exe"
| where ProcessCommandLine has_any ("-enc", "-encodedcommand", "frombase64string")
| extend EncodedCommand = extract(@"-enc(?:odedcommand)?\s+([A-Za-z0-9+/=]+)", 1, ProcessCommandLine)
| project Timestamp, DeviceName, AccountName, ProcessCommandLine, EncodedCommand
| order by Timestamp desc
```

### 8. Ransomware Indicators

**Use Case:** Detect potential ransomware activity based on file operations

```kql
DeviceFileEvents
| where Timestamp > ago(1h)
| where ActionType == "FileRenamed"
| where FileName endswith_any (".encrypted", ".locked", ".crypto", ".crypt", ".enc")

| order by FilesEncrypted desc
```

## 🚨 Incident Response

### 9. Incident Timeline Builder

**Use Case:** Build a timeline of events for a specific device during incident investigation

```kql
let investigationDevice = "DEVICE-NAME-HERE";
let investigationStart = ago(24h);
let investigationEnd = now();
union 
    (DeviceProcessEvents 
    | where DeviceName == investigationDevice 
    | where Timestamp between (investigationStart .. investigationEnd)
    | project Timestamp, EventType = "Process", Details = strcat("Process: ", FileName, " | CMD: ", ProcessCommandLine)),
    (DeviceNetworkEvents 
    | where DeviceName == investigationDevice 
    | where Timestamp between (investigationStart .. investigationEnd)
    | project Timestamp, EventType = "Network", Details = strcat("Connection to ", RemoteIP, ":", RemotePort)),
    (DeviceFileEvents 
    | where DeviceName == investigationDevice 
    | where Timestamp between (investigationStart .. investigationEnd)
    | project Timestamp, EventType = "File", Details = strcat(ActionType, ": ", FileName)),
    (DeviceLogonEvents 
    | where DeviceName == investigationDevice 
    | where Timestamp between (investigationStart .. investigationEnd)
    | project Timestamp, EventType = "Logon", Details = strcat(ActionType, " by ", AccountName))
| order by Timestamp asc
```

### 10. Alert Correlation by Device

**Use Case:** Correlate multiple alerts for a device to identify attack patterns

```kql
AlertInfo
| where Timestamp > ago(7d)
| join kind=inner (
    AlertEvidence
    | where EntityType == "Machine"
) on AlertId
| summarize 
    AlertCount = count(),
    AlertCategories = make_set(Category),
    AlertTitles = make_set(Title),
    Severities = make_set(Severity),
    FirstAlert = min(Timestamp),
    LastAlert = max(Timestamp)
    by DeviceName
| where AlertCount >= 3
| extend Duration = datetime_diff('hour', LastAlert, FirstAlert)
| project DeviceName, AlertCount, Duration, AlertCategories, AlertTitles, Severities
| order by AlertCount desc
```

### 11. User Risk Assessment

**Use Case:** Identify high-risk users based on failed logons and alerts

```kql
let failedLogons = DeviceLogonEvents
| where Timestamp > ago(7d)
| where ActionType == "LogonFailed"
| summarize FailedLogonCount = count() by AccountName;
let userAlerts = AlertEvidence
| where Timestamp > ago(7d)
| where EntityType == "User"
| summarize AlertCount = count() by AccountName;
failedLogons
| join kind=fullouter userAlerts on AccountName
| extend 
    AccountName = coalesce(AccountName, AccountName1),
    FailedLogonCount = coalesce(FailedLogonCount, 0),
    AlertCount = coalesce(AlertCount, 0)
| extend RiskScore = (FailedLogonCount * 2) + (AlertCount * 10)
| where RiskScore > 0
| project AccountName, FailedLogonCount, AlertCount, RiskScore
| order by RiskScore desc
```

## 📋 Compliance and Auditing

### 12. Privileged Account Monitoring

**Use Case:** Track all activities performed by privileged accounts

```kql
let privilegedAccounts = dynamic(["admin", "administrator", "domain admin", "enterprise admin"]);
union
    (DeviceLogonEvents
    | where Timestamp > ago(7d)
    | where AccountName has_any (privilegedAccounts)
    | project Timestamp, EventType = "Logon", AccountName, DeviceName, LogonType, RemoteIP),
    (DeviceProcessEvents
    | where Timestamp > ago(7d)
    | where AccountName has_any (privilegedAccounts)
    | project Timestamp, EventType = "Process", AccountName, DeviceName, FileName, ProcessCommandLine)
| order by Timestamp desc
```

### 13. Data Exfiltration Detection

**Use Case:** Identify large file transfers to external locations

```kql
DeviceNetworkEvents
| where Timestamp > ago(24h)
| where RemoteIPType == "Public"
| where ActionType == "ConnectionSuccess"
| summarize 
    TotalConnections = count(),
    DataSent = sum(SentBytes),
    DataReceived = sum(ReceivedBytes),
    UniqueIPs = dcount(RemoteIP)
    by DeviceId, DeviceName, InitiatingProcessFileName
| where DataSent > 100000000 // More than 100MB
| extend DataSentMB = round(DataSent / 1048576.0, 2)
| project DeviceName, InitiatingProcessFileName, TotalConnections, DataSentMB, UniqueIPs
| order by DataSentMB desc
```

### 19. Anomaly Detection - Unusual Logon Times

**Use Case:** Detect logons happening outside normal business hours

```kql
DeviceLogonEvents
| where Timestamp > ago(7d)
| where ActionType == "LogonSuccess"
| extend Hour = datetime_part('hour', Timestamp)
| where Hour < 6 or Hour > 20 // Outside 6 AM - 8 PM
| summarize 
    OffHoursLogons = count(),
    LogonTimes = make_set(Timestamp)
```

## 🎓 Query Optimization Tips

### Best Practices Applied in These Examples

1. **Time Filters**: All queries include `Timestamp > ago(Xd)` to limit data scanning
2. **Early Filtering**: WHERE clauses are applied before aggregations
3. **Specific Projections**: Only necessary columns are selected
4. **Efficient Operators**: Using `has_any`, `in~`, and other optimized operators
5. **Result Limiting**: Top N results or take clauses to limit output
6. **Summarization**: Aggregating data to reduce result set size

### Performance Comparison

**❌ Inefficient:**
```kql
DeviceInfo 
| summarize count() by OSPlatform 
| where OSPlatform == "Windows"
```

**✅ Optimized:**
```kql
DeviceInfo 
| where Timestamp > ago(1d)
| where OSPlatform == "Windows"
| summarize count()
```
